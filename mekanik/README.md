# mekanik

Sahip: YSY. Şasi, palet modülü, fırça taşıyıcı; SolidWorks dosyaları, teknik resimler, hesaplar.

- `hesaplar/hesaplar_rev3.py` – Rev. 3 ön boyutlandırma (kütle, tork, çekiş, enerji, hidrolik, rüzgâr). Çalıştır: `python hesaplar_rev3.py`
- `fig_boyut3.png`, `fig_kuvvet3.png` – yerleşim ve serbest cisim diyagramı (R1 raporundaki şekiller)
- CAD klasör önerisi: `cad/parcalar/`, `cad/montajlar/`, `cad/teknik_resim/`
